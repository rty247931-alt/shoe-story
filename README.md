# 👟 متجر الأحذية — نسخة كاملة (فرونت إند + باك إند + لوحة أدمن)

مشروع متجر إلكتروني جاهز للتشغيل محلياً، يحتوي على:
- متجر للعميل (رئيسية، منتجات، فلترة، سلة، دفع، تتبع طلب، حساب شخصي)
- لوحة تحكم أدمن كاملة (Dashboard، منتجات، أقسام، طلبات وفواتير، عملاء، وسائل دفع، إعدادات المتجر)
- تسجيل دخول موحّد للعميل والأدمن من نفس الصفحة
- قاعدة بيانات بسيطة مبنية على ملف JSON (لا تحتاج تثبيت أي قاعدة بيانات خارجية)

---

## 🚀 طريقة التشغيل (خطوة بخطوة)

### 1. تثبيت Node.js
لازم يكون عندك Node.js مثبت على جهازك (نسخة 18 أو أحدث).
لو مش مثبت، حمّله من هنا: https://nodejs.org (اختار نسخة LTS)

للتأكد إنه مثبت، افتح Terminal / CMD واكتب:
```
node -v
```

### 2. فك ضغط الملف
فك ضغط الملف المضغوط اللي استلمته في أي مكان على جهازك.

### 3. تثبيت المكتبات المطلوبة
افتح Terminal / CMD، وادخل لمجلد السيرفر:
```
cd shoe-store/server
npm install
```
هيحمّل المكتبات المطلوبة (Express, JWT... إلخ) — يحتاج اتصال بالإنترنت أول مرة فقط.

### 4. (اختياري للتشغيل المحلي) إعداد متغيرات البيئة
لو عايز تجرب المشروع محلياً بس، مش لازم تعمل حاجة — هيشتغل بقيم افتراضية آمنة للتجربة.
لو عايز تجهزه بنفس إعدادات الإنتاج من دلوقتي:
```
cp .env.example .env
```
وعدّل `JWT_SECRET` بقيمة عشوائية (شوف قسم "رفع المتجر أونلاين" تحت لمعرفة الطريقة).

### 5. تشغيل المشروع
```
npm start
```
هيظهرلك في الـ Terminal:
```
🟢 المتجر شغال على: http://localhost:3000
🔐 لوحة الأدمن: http://localhost:3000/admin/login.html
```

### 6. افتح المتجر
افتح المتصفح على:
```
http://localhost:3000
```

---

## 🔐 حساب الأدمن الافتراضي
أول ما تشغل المشروع، بيتعمل حساب أدمن تلقائي:

- **البريد الإلكتروني:** admin@store.com
- **كلمة السر:** admin123

سجّل الدخول من صفحة تسجيل الدخول العادية `/login.html` — هيحولك تلقائياً للوحة الأدمن لأن حسابك دوره "أدمن".

⚠️ **مهم جداً:** بعد أول تشغيل، ادخل لصفحة "حسابي" وغيّر كلمة السر فوراً، خصوصاً لو هترفع المتجر أونلاين.

---

## 📁 إدارة البيانات
كل بيانات المتجر (المنتجات، الطلبات، العملاء، الإعدادات) بتتخزن تلقائياً في:
```
server/data/db.json
```
والصور المرفوعة بتتخزن في:
```
server/uploads/
```
ينفع تاخد نسخة احتياطية من المجلدين دول بشكل دوري.

---

## 💳 وسائل الدفع
من لوحة الأدمن → "وسائل الدفع" تقدر:
- تفعّل/تعطّل فودافون كاش وتحط رقمك
- تفعّل/تعطّل إنستا باي وتحط حسابك
- تفعّل/تعطّل الدفع عند الاستلام (مع إمكانية إضافة رسوم)
- تجهّز بيانات الربط مع Paymob للبطاقات الائتمانية

**ملاحظة:** الدفع بفودافون كاش وإنستا باي في هذا الإصدار يعمل كـ"تأكيد يدوي" — العميل يحوّل ثم يأكد الطلب، وعليك مراجعة التحويل يدوياً من حسابك قبل شحن الطلب. الربط الفعلي مع بوابة Paymob للبطاقات يحتاج حساب Paymob موثّق ومفاتيح API حقيقية منهم، ودمج فعلي إضافي عند الرغبة في التفعيل الكامل.

## 🌐 رفع المتجر أونلاين

### قائمة تحقق قبل النشر (مهم جداً)
1. اعمل نسخة من `server/.env.example` باسم `server/.env` واملأ:
   - `NODE_ENV=production`
   - `JWT_SECRET` — قيمة عشوائية طويلة (السيرفر هيرفض الشغل في production لو سايبها فاضية أو الافتراضية). تقدر تولّد واحدة بـ:
     ```
     node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
     ```
2. سجّل دخول بحساب الأدمن الافتراضي وغيّر كلمة السر فوراً من صفحة "حسابي" (السيرفر هيطبعلك تحذير في الـ logs لو لسه على `admin123`).
3. اتأكد إن مجلد التخزين (`server/data` و `server/uploads`، أو المسار المحدد في `STORAGE_DIR`) دائم (persistent) على المنصة اللي هترفع عليها — غير كده هتفقد البيانات والصور مع كل إعادة نشر.

### الخيار 1: Render.com (فيه ملف جاهز `render.yaml`)
1. ارفع المشروع على مستودع GitHub.
2. من لوحة Render: New → Blueprint، واختَر المستودع — هياخد الإعدادات تلقائياً من `render.yaml` (بيعمل provision لقرص دائم `/var/data` ويولّد `JWT_SECRET` تلقائياً).
3. بعد أول نشر، افتح الرابط اللي هيديهولك Render.

### الخيار 2: Railway.app
1. New Project → Deploy from GitHub repo.
2. في إعدادات الخدمة: Root Directory = `server`، Start Command = `node server.js`.
3. من تبويب Variables ضيف `NODE_ENV=production` و `JWT_SECRET` (قيمة عشوائية).
4. من تبويب Volumes: اعمل Volume واربطه بمسار زي `/data`، وضيف متغير `STORAGE_DIR=/data` عشان البيانات والصور تفضل محفوظة بين كل نشر.

### الصور (اختياري لاحقاً)
افتراضياً الصور بتتخزن في نفس مجلد التخزين. لو حجم المتجر كبر، تقدر تنقلها لخدمة زي Cloudinary بدل التخزين المحلي.

## 🛠️ التقنيات المستخدمة
- Backend: Node.js + Express
- قاعدة البيانات: ملف JSON (بسيط وسهل، مناسب للمتاجر الصغيرة والمتوسطة)
- Frontend: HTML + CSS + JavaScript عادي (بدون فريم وورك، يفتح فوراً بدون build)
- الخط: Cairo — الألوان: أسود وذهبي
- تسجيل الدخول: JWT
- حماية إضافية: Helmet (هيدرز أمان)، Rate Limiting (ضد محاولات الدخول المتكررة)، Compression
- نقطة فحص صحة السيرفر: `GET /api/health`

## ❓ مشاكل شائعة
**"npm: command not found"** → لسه لم تثبت Node.js، ثبّته من الرابط فوق وأعد فتح الـ Terminal.

**البورت 3000 مستخدم من برنامج تاني** → شغّل بدل كده:
```
PORT=4000 npm start
```
(على ويندوز: `set PORT=4000 && npm start`)

**عايز ترجع البيانات للوضع الافتراضي** → امسح ملف `server/data/db.json` وأعد تشغيل السيرفر، هيتعمل من جديد تلقائياً.
