# متجر الأحذية — سيرفر حقيقي + قاعدة بيانات

ده نسخة **حقيقية** من المتجر: سيرفر Node.js متصل بقاعدة بيانات PostgreSQL فعلية.
كل البيانات (المنتجات، الطلبات، الإعدادات، حساب المدير) محفوظة في قاعدة البيانات مش في المتصفح — يعني أي حد يفتح الموقع من أي جهاز هيشوف نفس البيانات، ومزامنة بين كل الأجهزة.

## بيانات دخول الإدارة الافتراضية
- البريد: `admin@store.com`
- الباسورد: `admin123`
(غيّرهم فورًا بعد أول دخول من تبويب "الحساب")

## إزاي ترفعه على Suga (الطريقة الموصى بها ليك)

### 1. جهّز المشروع على GitHub
- اعمل حساب على github.com لو معندكش.
- اعمل مستودع (Repository) جديد، وارفع عليه محتويات المجلد ده بالكامل (ملف server.js وباقي الملفات).
  - أسهل طريقة: من صفحة الريبو الجديد، اختار "uploading an existing file" واسحب كل الملفات، أو استخدم GitHub Desktop لو عايز حاجة أسهل بالسحب والإفلات.

### 2. سجّل في Suga
- ادخل على suga.app واعمل حساب مجاني (فيه خطة Free من غير أي بطاقة).

### 3. اعمل مشروع جديد واربطه بالـ GitHub
- من لوحة Suga، "New Project" → اختار "Deploy from GitHub" → اختار الريبو اللي رفعته.
- Suga هيكتشف إنه مشروع Node.js تلقائيًا ويبنيه (فيه Dockerfile جاهز في المشروع لو احتجته).

### 4. ضيف قاعدة بيانات PostgreSQL
- على نفس الـ Canvas، اسحب قالب **PostgreSQL** وحطه جنب السيرفس بتاعك.
- Suga هيوصّل بينهم تلقائيًا ويوفر متغير `DATABASE_URL` جاهز للسيرفس — تأكد إنه موصول من إعدادات الـ Environment Variables بتاعة السيرفس.

### 5. ضيف متغير الأمان
- في Environment Variables بتاعة السيرفس، ضيف:
  - `JWT_SECRET` = أي نص عشوائي طويل وسري (مثال: `x7K9pQz...`)
- `DATABASE_URL` هيكون موجود تلقائيًا لو ربطت قاعدة البيانات في الخطوة اللي فاتت.

### 6. اعمل Deploy
- دوس Deploy، واستنى شوية لحد ما يخلص البناء.
- هتاخد رابط جاهز (زي `yourproject.suga.app`) — افتحه وهتلاقي المتجر شغال.

### 7. أول حاجة تعملها
- ادخل من "⚙️ الإدارة" بالبيانات الافتراضية فوق، وغيّر الإيميل والباسورد فورًا من تبويب "الحساب".

## تجربته على جهازك الشخصي (اختياري، قبل الرفع)

محتاج:
1. Node.js متثبت على جهازك.
2. قاعدة بيانات PostgreSQL — أسهل حل إنك تعمل حساب مجاني على [neon.tech](https://neon.tech) أو [supabase.com](https://supabase.com) وتاخد رابط `DATABASE_URL` منهم مباشرة (مش لازم تثبت Postgres على جهازك).

الخطوات:
```bash
cd server
cp .env.example .env
# افتح ملف .env وحط رابط قاعدة البيانات ومفتاح JWT_SECRET
npm install
npm start
```
بعدين افتح المتصفح على `http://localhost:3000`.

## هيكل المشروع
```
server/
  server.js          -> نقطة تشغيل السيرفر
  db.js              -> الاتصال بقاعدة البيانات وإنشاء الجداول تلقائيًا أول مرة
  routes/             -> واجهات الـ API (تسجيل الدخول، المنتجات، الطلبات، الإعدادات)
  middleware/auth.js  -> حماية صفحات الإدارة
  public/index.html   -> واجهة المتجر ولوحة التحكم
  Dockerfile
  .env.example
```

قاعدة البيانات بتتبني تلقائيًا (الجداول + بيانات افتراضية) أول ما السيرفر يشتغل لأول مرة — مفيش خطوة يدوية مطلوبة غير ضبط `DATABASE_URL`.
